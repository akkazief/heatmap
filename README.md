# Тепловая карта расходов на первичную медицинскую помощь

Скрипт на Python, который строит тепловую карту (heatmap) долей расходов на первичную 
медико-санитарную помощь (PHC) в общих текущих расходах на здравоохранение (CHE) для нескольких стран по разным методикам 

## Что делает

- Спрашивает у пользователя список стран и значения (% от CHE) для каждого определения.
- Строит тепловую карту: цвет ячейки зависит от значения, число подписано внутри.
- Цвет текста подбирается автоматически по яркости ячейки, чтобы числа читались.
- Сохраняет результат в `phc_heatmap.png` и `phc_heatmap.pdf`.

## Почему данные вводятся вручную

Реальные данные, на которых я работал, не публичные, поэтому в репозитории их нет. Скрипт запрашивает страны и значения при запуске. Для проверки можно ввести любые тестовые числа.

## Определения по умолчанию

`WHO Global`, `De Jure`, `De Facto`, `Optimal`. Если нажать Enter при запросе определений, подставятся именно они. Можно ввести и свои названия через запятую.


## Установка и запуск

```bash
git clone <ссылка на репозиторий>
cd <папка проекта>
pip install -r requirements.txt
python heatmap.py
```

Пример ввода:

```
Страны через запятую: Country A, Country B, Country C
Определения через запятую (Enter = WHO Global, De Jure, De Facto, Optimal):

Введи 4 чисел через пробел для каждой страны.
Порядок: WHO Global, De Jure, De Facto, Optimal
  Country A: 37 13 30 30
  Country B: 47 10 11 38
  Country C: 36 42 42 42
```

Числа вводятся через пробел, десятичная запятая тоже подходит. При ошибке (не число или неверное количество значений) скрипт переспросит.
